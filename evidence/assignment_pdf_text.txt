 
 
Assignment  
Implementation of FastSpeech 2-Based Text-to-Speech Synthesis 
Deadline: 07-11-2026 
1. Objective 
The objective of this assignment is to implement and evaluate the FastSpeech 2 Text-to-Speech (TTS) model 
separately for English and Telugu, referring to the original research paper and an available GitHub 
implementation. Applicants are expected to understand the model architecture, adapt and execute the existing 
codebase independently for each language, train two separate models using the specified datasets, generate 
speech samples, and analyse the duration, pitch and energy predictions of the variance adaptor for the given test 
smaples.  
References: FastSpeech 2 Paper  |  FastSpeech 2 GitHub implementation  
Note: Use the GitHub implementation as a starting point and document the changes made for each language, 
particularly for Telugu support.

Technical Report 
The report must include the following details and analysis: 
• Implementation approach, architecture components used from the reference implementation, and 
modifications made for English and Telugu. 
• Dataset selection, subsampling, preprocessing, train/validation split, and training configuration for each 
language. 
• Analysis of training and validation loss curves, including convergence behaviour and any instability or 
overfitting observed. 
• Observations on the generated speech, including pronunciation, and overall speech quality for the provided 
each test sentence. 
• Analysis of the variance-adaptor plots for duration, pitch (F0) and energy, with explanations of the 
observed patterns for each of the test sentence. 
• Comparative observations between the English and Telugu models, including limitations, failures and 
possible improvements based on the test sentences that are provided. 
• Reproducibility details, including software dependencies, configuration files and commands required to 
preprocess, train and run inference.
